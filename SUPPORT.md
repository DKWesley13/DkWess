# Support

For public, non-sensitive questions about installation, usage, findings, documentation, or feature ideas, open a GitHub issue.

Before opening an issue:
1. run `dkwess-securerepo --version`;
2. check `docs/GETTING_STARTED.md` and `docs/FAQ.md`;
3. for a rule, run `dkwess-securerepo --explain RULE_ID`.

Do not place credentials, private repositories, customer data, exploit details, or sensitive logs in public issues. Follow `SECURITY.md` for suspected SecureRepo vulnerabilities.

When safe, include SecureRepo version, OS, Python version, command used, rule ID, sanitized reproduction, expected behavior and actual behavior.
